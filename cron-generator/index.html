    FAQ

    What is a cron expression generator?

    A cron expression generator helps you build the five-field schedule string used by cron (minute, hour, day of month, month, day of week). This page turns common field choices into a cron string, a plain-English summary, and sample next run times in your browser.

    Does this cron generator upload my schedule?

    No. Expression building, explanation, and next-run estimates run entirely in your browser. Nothing is uploaded, logged, or stored on a server.

    Which cron format does this tool use?

    Standard 5-field cron: minute hour day-of-month month day-of-week. It does not emit a leading seconds field (some Quartz/Spring schedules use 6 or 7 fields). Day-of-week uses 0–6 with Sunday as 0, and also accepts names like SUN.

    How accurate are the next run times?

    Next runs are computed locally from your browser clock using the five fields you set. They assume standard cron matching when both day-of-month and day-of-week are constrained (OR semantics like classic Vixie cron). Time zone is your local zone as reported by the browser—not a server timezone.

    Can I paste an existing cron expression?

    Yes. Paste a 5-field expression into the Cron string box. The page re-parses it, updates the human-readable summary, and refreshes sample next runs when the expression is valid.
